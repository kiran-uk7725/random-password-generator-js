# 🔑 Random Password Generator

A responsive, lightweight web application built using HTML, CSS, and Vanilla JavaScript. This tool helps users generate secure, random passwords containing a combination of uppercase letters, lowercase letters, numbers, and special symbols.

## 🚀 Features

- ⚡ **Instant Password Generation:** Generates a strong 12-character random password at the click of a button.
- 📋 **Copy to Clipboard:** Easily copy the generated password with a single click.
- 🎨 **Clean & Responsive UI:** Styled modern layout suitable for mobile and desktop screens.
- ⚡ **Zero Dependencies:** Built purely using native HTML, CSS, and Vanilla JavaScript.

## 🛠️ Built With

- **HTML5** (Semantic layout structure)
- **CSS3** (Flexbox, custom styling)
- **JavaScript (ES6)** (Random generation logic & Clipboard API)
